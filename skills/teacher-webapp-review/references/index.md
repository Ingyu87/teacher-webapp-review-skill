# 활동별 목차

자기 앱과 요청에 해당하는 활동 파일만 읽습니다. 각 파일의 프롬프트는 참고 예시이며 자동 실행할 명령 목록이 아닙니다.

## 공통 보안 점검

- [1 내 앱의 기능과 시험 환경 정리](activity-01.md) — 처음 점검하거나 프로젝트 구조를 아직 모르는 경우

- [2 F12로 교사용 비밀번호 찾기](activity-02.md) — 교사용 비밀번호나 화면 잠금 기능이 있는 경우

- [3 로그인 없이 보호 자료가 열리는지 확인](activity-03.md) — 로그인이 필요한 화면이나 자료가 있는 경우

- [4 다른 학생과 교사의 자료 접근 확인](activity-04.md) — 개인별 기록이나 학급별 자료가 있는 경우

- [5 API 키와 환경 변수의 노출 점검](activity-05.md) — 외부 API나 배포 환경 변수를 사용하는 경우

- [6 보내는 정보와 외부 AI 전송 확인](activity-06.md) — 서버나 외부 AI에 입력을 보내는 경우

- [7 오류 응답과 기록의 비밀정보 제거](activity-07.md) — 서버 오류나 운영 기록을 남기는 경우

- [8 로그인과 AI 요청 횟수 제한](activity-08.md) — 반복 요청으로 비용이나 서비스 장애가 생길 수 있는 경우

- [9 사용량과 대기 서버 비용 점검](activity-09.md) — 배포·데이터베이스·AI 등 과금 가능한 서비스를 사용하는 경우
