# 38 수업 종료와 재개 기능 확인

분류: 사용 종료와 서비스 정리

사용하는 경우: 앱 전체는 계속 운영하면서 특정 수업의 새 참여·제출·AI 요청만 끝내려는 경우

준비할 정보: 대상 수업, 교사 권한, 미제출 입력 처리, 진행 중 요청 처리, 기존 기록 조회 범위, 가상 계정

### 어디서 확인하나요

가상 학생 창에서 F12 → Network → Fetch/XHR을 연 뒤 제출합니다. 방금 생긴 실제 요청의 Headers와 Response를 비교합니다. 교사 창에서 대상 수업을 종료한 뒤 기존 학생 창에서 다시 제출합니다. 기록 추가와 외부 AI 호출 여부는 서버·저장소·호출 기록에서 따로 확인합니다. 버튼이 사라져도 서버 차단이 확인된 것은 아닙니다.

### 구현할 때 적용할 조건

- 종료할 수업과 안내 문구, 미제출 입력의 보존·폐기, 진행 중 요청의 완료·취소 중 내가 선택할 내용을 먼저 물어봐 줘.

- 기존 종료 기능이 충분하면 유지해 줘. 기능이 없고 내가 추가를 선택했을 때만 최소 수정안을 구현해 줘.

- 종료 상태를 서버에서 검사해 새 참여·제출·AI 요청을 막고, 이미 열린 창과 화면을 거치지 않는 요청도 검사해 줘.

- 담당 교사만 종료·재개할 수 있게 하고 기존 기록과 다른 수업은 유지해 줘. 이미 시작한 외부 호출의 취소 가능 여부와 발생 비용은 별도 확인해 줘.

### 1 현재 상태부터 확인하기

사용할 때: 프로젝트를 연 뒤 처음 보냅니다. 파일을 고치기 전 단계입니다.

```text
활동: 수업 종료와 재개 기능 확인
앱 이름과 프로젝트: [입력]
이번 시험 주소: [입력]
준비 정보: 대상 수업, 교사 권한, 미제출 입력 처리, 진행 중 요청 처리, 기존 기록 조회 범위, 가상 계정
현재 상황: [입력]
사용할 가상 자료: [입력]

이 활동에 해당하는지부터 확인해 줘. 아직 파일이나 설정은 수정하지 마.
1. 대상 수업의 상태를 저장하는 위치와 참여·제출·AI 요청을 처리하는 서버 경로를 찾아 줘. 종료 기능이 이미 있는지부터 확인해 줘.
2. 교사가 종료할 때 새 요청과 이미 처리 중인 요청, 학생 창의 미제출 입력을 각각 어떻게 처리하는지 확인해 줘.
3. 수업 종료와 앱 전체 중단을 구분하고, 다른 수업·기존 답안·교사 결과 조회에 미칠 영향을 설명해 줘.
4. 종료·재개 권한을 서버에서 확인하는지 살펴봐 줘. 기능이 없다는 사실만으로 취약점이나 필수 조치라고 단정하지 마.

결과는 표로 정리해 줘. 표에는 확인 항목, 현재 동작, 근거가 있는 파일이나 설정 위치, 발견한 문제와 추가로 확인할 내용을 적어 줘. 코드에서 확인한 사실과 추정은 구분해 줘. 내가 직접 확인할 메뉴·버튼·파일 이름도 알려 줘. 파일을 읽지 못했다면 그 사실을 표시해 줘.
실제 학생 정보·비밀키·인증 토큰은 출력하지 말고 필요한 값은 가려 줘. 내 앱 또는 허락받은 시험 환경만 대상으로 해 줘.
참고할 확인 위치: 가상 학생 창에서 F12 → Network → Fetch/XHR을 연 뒤 제출합니다. 방금 생긴 실제 요청의 Headers와 Response를 비교합니다. 교사 창에서 대상 수업을 종료한 뒤 기존 학생 창에서 다시 제출합니다. 기록 추가와 외부 AI 호출 여부는 서버·저장소·호출 기록에서 따로 확인합니다. 버튼이 사라져도 서버 차단이 확인된 것은 아닙니다.
```

다음 행동: 현재 구조와 해당 여부를 확인합니다. 모르는 정보는 먼저 확인하고, 수정이 필요하면 2번으로 진행합니다.

변경할 파일, 학생 또는 교사 화면에서 달라질 부분, 필요한 관리 설정, 시험할 가상 입력을 순서대로 적어 줘. 서버가 없는 앱이라면 지금 할 수 있는 것과 서버가 필요한 것을 분리해 줘.
아직 코드를 수정하거나 서비스를 만들지 마. 내가 결정해야 할 사항이 있으면 선택지와 차이를 설명하고 물어봐 줘.

다음 행동: 수정할 내용과 비용, 정보 수집·전송·보관 방식이 달라지는지 확인한 뒤 진행할 방법을 정합니다. 학교가 판단해야 하는 내용은 먼저 확인합니다.

확인할 자료가 실제로 없으면 없다고 말하고 필요한 시험 준비를 설명해 줘. 캡처 요청에는 가려야 할 정보도 알려 줘. 실제 학생 정보·비밀키·인증 토큰은 출력하지 말고 필요한 값은 가려 줘. 내 앱 또는 허락받은 시험 환경만 대상으로 해 줘.
